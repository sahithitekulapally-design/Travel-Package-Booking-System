TRIPNEST — TRAVEL PACKAGE MANAGEMENT SYSTEM
============================================

Project type: Front-end demo (HTML, CSS, JavaScript)
Features:
- Browse six sample travel packages
- Filter by Beach, Mountain, and City
- Search by package/destination
- Choose a package and submit a booking request
- Save and view bookings in browser localStorage
- Responsive layout for mobile and desktop

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Browse packages and submit a sample booking.

IMPORTANT
- This is a student/demo project. It does not connect to a server or payment gateway.
- Booking requests are stored only in the current browser on the current device.
- Sample packages, prices, and photos are for demonstration and are not live offers.
- Internet is required for the remote package photos and Google Fonts.
- For a production system, add a backend/database, authentication, server-side validation,
  secure admin controls, booking confirmation, and payment integration.
